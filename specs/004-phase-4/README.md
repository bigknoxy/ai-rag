# Phase 4: UI, Tests, CI, Docs

## Overview
This phase adds a Blazor demo UI, enhances tests, sets up full CI/CD with Docker, and documents ADRs for architectural decisions.

## Goals
- Provide a simple web UI for ingestion, querying, and streaming.
- Ensure comprehensive testing (unit, integration, E2E).
- Enable easy deployment via Docker.
- Document key decisions in ADRs.

## Deliverables
- Blazor Server app integrated with API.
- Playwright E2E tests.
- GitHub Actions for build/test/Docker.
- Updated documentation with UI and Docker guides.
- ADRs for model/vector store choices and local-first rationale.
